# Changelog

All notable changes to Image Size Checker Pro. Each version is also a tagged GitHub Release with the exact ZIP that went to the stores.

## 3.5.0

Image Size Checker Pro now has a project website with screenshots, install links, the changelog and the privacy policy. The store listing explains more clearly what makes it different: savings are measured by really compressing each image, and you get files with the same name, format and dimensions. How the extension works is unchanged, and your settings carry over.

- New project website: https://r3hab-media.github.io/Image-Size-Checker-Pro/
- The extension's details page links to the website.
- The privacy policy link in settings opens the website's copy of the policy.
- Shorter, clearer store description.
- Fixed: the side panel no longer shows its own "Side panel" button.
- No new permissions.
- A Firefox version is built from the same code and will be submitted to Firefox Add-ons.

## 3.4.1 (October 19, 2026)

- Works the same in Microsoft Edge as in Chrome. Links and button labels name the browser you are using.
- First release on Microsoft Edge Add-ons.

## 3.4.0 (October 18, 2026)

First release on the Chrome Web Store.

- Audits every image on a page: file size, pixel dimensions, aspect ratio, alt text, and layout shift and LCP risks.
- Measures achievable savings by really compressing each image.
- Compresses images as drop-in replacements with the same name, format and dimensions. PNG is lossless.
- Resizes oversized images to 1x and 2x of their displayed size, with srcset markup.
- Optional WebP copies with `<picture>` markup, and optional lossy PNG.
- Before and after preview with a quality slider.
- Saves to a folder you choose, or through the Save-As dialog, one image at a time or as a ZIP.
- Optional side panel, and keyboard shortcuts you set yourself.
